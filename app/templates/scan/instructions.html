Scan Reseau - Instructions

1. Installer les prerequis

Sur le poste Windows de l'AWEM/ALEM qui a acces au reseau local :

  1. Installer Python 3.11+ : python.org
  2. Ouvrir un terminal et lancer :
pip install requests wmi pythoncom

Sur Windows, wmi et pythoncom sont inclus dans pywin32 qui s'installe via pip install pywin32

2. Telecharger le script

Copier le fichier scanner_local.py sur le poste cible.

3. Lancer le scan

Ouvrir un terminal en tant qu'administrateur et lancer :

python scanner_local.py --url https://parc-anem-production.up.railway.app --token {{ api_token }} --site "{{ site_utilisateur }}"

Si le reseau n'est pas detecte automatiquement :

python scanner_local.py --url https://parc-anem-production.up.railway.app --token {{ api_token }} --site "{{ site_utilisateur }}" --cidr 192.168.100.0/24
4. Resultat

Le scan envoie automatiquement les PC et imprimantes trouves a la base de donnees centrale. Les donnees apparaissent sur l'inventaire et les imprimantes sans intervention.

Reexecuter le scan regulierement pour garder les donnees a jour.
